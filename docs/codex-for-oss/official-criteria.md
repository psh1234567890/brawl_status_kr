# Codex for Open Source 공식 기준 확인

- 확인일: 2026-07-25
- 기준: 아래 OpenAI 공식 페이지의 현재 공개 내용

## 공식 출처

- [프로그램 안내](https://developers.openai.com/community/codex-for-oss)
- [신청서](https://openai.com/form/codex-for-oss/)
- [프로그램 약관](https://learn.chatgpt.com/docs/codex-for-oss-terms)

## 확인 결과

1. **신청 대상**: 활성 오픈소스 프로젝트의 maintainer가 신청할 수 있다. 안내 페이지는 core maintainer 또는 널리 쓰이는 공개 프로젝트 운영자를 권장하고, 기준에 정확히 맞지 않아도 생태계에서 중요한 역할을 한다면 설명과 함께 신청하라고 안내한다.
2. **공개 상태**: 신청서는 GitHub 프로필과 저장소를 public으로 설정하도록 명시한다.
3. **역할**: 신청서에서 `Primary maintainer` 또는 `Core maintainer`를 선택한다. 약관은 역할·권한·저장소 통제 증명을 추가로 요청할 수 있다고 밝힌다.
4. **심사 신호**: 저장소 사용량, 생태계 중요성, 실제 유지보수 증거를 본다. PR 리뷰, 이슈 분류, 릴리스 관리, 보안·코드 품질 유지가 예시다.
5. **혜택**: 선정된 유지보수자는 6개월 ChatGPT Pro와 Codex를 받을 수 있다. API 크레딧과 Codex Security는 추가·조건부 혜택이며 별도 검토나 조건이 적용될 수 있다.
6. **신청 필드**: 이름, ChatGPT 계정 이메일, 공개 GitHub 사용자명, 공개 저장소 URL, maintainer 역할, 저장소 자격 설명, 관심 혜택, OpenAI Organization ID, API 크레딧 사용 계획, 추가 설명을 요구한다.
7. **글자 제한**: `Why does this repository qualify?`, `How will you use API credits for your project?`, `Anything else we should know?`는 각각 최대 500자다.
8. **심사 방식**: 신청서는 rolling basis로 검토하며, 선정 시 이메일로 알린다.
9. **선정 보장 없음**: 약관은 신청이 선정·지원·접근을 보장하지 않으며 OpenAI가 재량으로 승인 또는 거절할 수 있다고 명시한다.
10. **정확성과 비밀정보**: 신청 정보는 정확하고 완전해야 하며 허위·오해 소지가 있는 정보는 거절·회수 사유가 될 수 있다. 신청 자료에 기밀정보를 넣지 않아야 한다.

## 공식 기준이 아닌 것

- 최소 GitHub 별 개수
- 최소 월간 사용자 수
- 최소 다운로드 수
- 특정 준비도 점수
- 신청하면 자동으로 선정된다는 보장

이 저장소에서 사용하는 준비도 점수와 4~6주 목표는 프로젝트 내부 의사결정용이며 OpenAI의 공식 합격 기준이 아니다.
