# 라이선스 결정 기록

## 결정

2026-07-25 사용자 승인에 따라 프로젝트의 **직접 작성한 소스 코드와 문서**를 MIT License로 공개한다. 저작권 표시는 `Copyright (c) 2026 psh1234567890`으로 기록했다.

- 짧고 이해하기 쉬워 개인 유지보수 프로젝트의 진입 장벽이 낮다.
- 사용·수정·배포·상업적 사용을 폭넓게 허용하면서 저작권·허가 고지 유지를 요구한다.
- Apache-2.0보다 문서 부담이 작다.

Apache-2.0은 명시적 특허 허여와 특허 소송 종료 조항이 중요할 때 유리하다. 현재 저장소에서 별도의 특허 포트폴리오나 특허 기여 정책은 확인되지 않았으므로 MIT가 더 단순한 기본값이다.

## 라이선스가 적용되지 않아야 하는 범위

- Supercell과 Brawl Stars의 상표, 명칭, 게임 이미지, 팬 키트 자산
- BrawlAPI·Brawlify·Brawl Stars API 등 제3자 데이터
- npm 의존성의 소스 코드
- 런타임 또는 생성 과정에서 받는 제3자 이미지·데이터

`LICENSE`와 함께 `NOTICE.md`, `THIRD_PARTY_NOTICES.md`를 유지하고 README에 “코드 라이선스가 제3자 자산 권리를 부여하지 않는다”고 명시해야 한다.
