## English

### My role

I am the repository owner and primary maintainer. I am responsible for product design, the Next.js/PostgreSQL implementation, deployment, data accuracy, security fixes, issue response, and releases. The connected GitHub account has verified admin, maintain, and push permissions.

### Why does this repository qualify?

Brawl Status KR is a public analytics service for Korean Brawl Stars players. It deduplicates recent battles gathered through searches, builds sample-based map, team, and counter statistics, and documents methodology and bias. On 2026-09-22 it held 60,268 stored battles and 1,606 unique stored tags; tags are not claimed as users. [Before submission: recheck the latest release and real external-feedback evidence.]

### How will you use API credits for your project?

I will use API credits to classify new issues, create Korean/English summaries, flag possible duplicate reports, summarize PR changes and risks, suggest missing tests, and draft release notes and weekly maintainer digests. AI will not close issues or approve or merge PRs. Security and personal data will be excluded from public summaries, and a maintainer will review every result.

### Anything else we should know?

This is a small public service for the Korean game-data ecosystem, not a widely adopted project. I will not inflate usage, stars, or contributions; stored tags and users remain separate metrics. The project documents sampling bias and third-party fan-content rights. Support would help turn repetitive maintenance and data-accuracy review into a transparent, contributor-friendly process.
