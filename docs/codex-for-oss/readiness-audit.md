## 신청 전 차단 요소

제품 `v0.1.0` 릴리스 차단 요소는 현재 체크리스트상 남아 있지 않다. 아래는 Codex for Open Source 신청 전에 더 확보할 근거다.

1. 개인정보 최소화와 동의 필요성을 검토한 최근 방문·성공 검색·재방문 측정
2. 실제 외부 사용자의 피드백 또는 기여
3. 릴리스 이후의 지속적인 이슈 응답·수정 기록
