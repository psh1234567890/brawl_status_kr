# 수익화 실행 현황

작성: 2026-10-13. 사이트: https://www.brawl-o1.site/.

## 1. 먼저 측정한다

비공개 운영 화면 `/admin/usage`에서 기존 방문 세션·검색·게임 종료와 신규 PV·브라우저 세션·재방문·저장·비교·공유·재조회 횟수를 구분한다. 기존 운영자 인증과 허용 목록을 그대로 사용한다.

| 지표 | 정의와 범위 | 판단에 쓰는 방법 |
| --- | --- | --- |
| PV | 브라우저에서 경로가 바뀌거나 문서를 새로 불러올 때의 조회 횟수. admin/API 제외. URL·검색어 미전송 | 유입 증가가 실제 페이지 이용으로 이어지는지 확인 |
| 브라우저 세션 | 이전 페이지 조회와 30분 이상 간격인 조회. localStorage 사용 가능 브라우저만 | 기간별 이용량의 근삿값 |
| 7일 내 재방문 세션 비중 | 새 브라우저 세션 중 이전 조회가 7일 이내인 횟수 ÷ 측정 브라우저 세션 | 기기 내 재이용 신호. 사람 수·D7 코호트 유지율로 해석하지 않음 |
| 저장·비교·공유·재조회 | 성공한 저장/해제, 비교 진입, 두 프로필 로딩 완료, 공유/복사 완료, 저장·최근 태그 다시 조회의 실행 횟수 | 재방문 경로의 사용 여부. 사용자 전환율로 해석하지 않음 |
| 월 수익·비용 차액 | 실제 광고+스폰서+순수 후원 수익 − 호스팅·DB·도메인 월 환산·기타 비용 | 먼저 운영비 충당 여부 확인. 미확인 항목은 빈칸, 확인된 무수익/무료 항목만 0 |

새 지표는 배포 이후부터 수집한다. 시각은 KST로 표시하며 오늘·최근 7개 날짜·전체 누적을 구분한다. 새 지표의 시작 시각도 별도 표시한다. 상세 시간대 집계는 기존 90일 보관 정책, 익명 누적 합계는 기존 장기 보관 정책을 따른다. 전송은 고정 이벤트 이름만 사용한다. 페이지 진입 관련 이벤트는 최대 4개를 한 요청·한 DB 왕복으로 묶는다. opt-out과 preview/E2E 제외 규칙을 유지한다.

재방문 분류는 저장소 초기화/차단, 여러 탭·기기, 네트워크 실패와 클라이언트가 보낸 이벤트의 영향을 받는다. 서버에 방문자 식별자를 추가하지 않으므로 정확한 개인별 전환/코호트는 산출하지 않는다.

운영비 입력값은 선택 월별로 이 브라우저에 최대 24개월 저장되며 서버/다른 기기에 동기화되지 않는다. 청구서와 광고 보고서에서 직접 확인한 금액을 입력한다. 계정번호나 지급 정보를 입력하지 않는다.

### 확인한 기준선

- Search Console, `https://www.brawl-o1.site/`, 2026-09-13~2026-10-10: Google 검색 클릭 1,269회, 노출 9,313회. 직전 28일 클릭 756회. 전체 사이트 방문/PV가 아니다.
- 같은 GSC 기간: 메인 페이지 클릭 700회, `/brawlers` 355회. 페이지별 검색 유입 근거이며 재방문/매출 근거는 아니다.
- 운영 DB `brawl_win_data`의 익명 시간대 집계 조회(2026-10-13, 배포 전): 방문 세션 254, 검색 성공 210, 실패 13. 최근 28일 조건으로 조회했지만 첫 데이터는 KST 10월 11일로, 28일 전체 측정치가 아니다.
- 연결된 GSC Wizard에는 GA4 읽기 연결이 없었다. GA4가 사이트에 전혀 없다는 뜻은 아니다.
- 월 운영비·광고 승인·실제 광고 수익은 미확인. 임의 RPM이나 수익 예측을 사용하지 않는다.
- Vercel 청구 조회 API는 해당 팀에 대해 `Plan not found`를 반환해 비용을 확보하지 못했다. 이를 무료/0원으로 해석하지 않는다.

주 1회 같은 정의·기간으로 확인한다. 저장·재조회 횟수와 재방문 세션 비중이 증가하는지, 검색 성공률·API 5xx·응답 시간이 악화하는지 함께 본다. 수치 목표는 기준선이 쌓인 뒤 정한다.

## 2. 재방문 경로

검색한 공개 플레이어의 이름·태그·트로피·조회 시각을 이 기기에 최대 12개 보관한다. 30일이 지난 캐시는 읽을 때 제외한다. 캐시는 마지막 조회값으로, 실시간 프로필이나 자동 추적이라고 표시하지 않는다.

메인의 저장·최근 태그에 마지막 조회 이름/트로피를 표시한다. 다시 조회하면 지난 조회 대비 실제 트로피 차이를 확인한다. 계정 대시보드의 기본 태그·최근 태그·저장한 플레이어는 해당 태그가 입력된 메인 조회로 연결한다. 추가 자동 수집이나 로그인 의무화를 도입하지 않는다.

## 3. 검색 유입

유입이 확인된 브롤러 도감에 공개 카탈로그와 보유 목록의 차이, 보유 브롤러 확인 방법, 맵별 표본 추천 사용법을 10개 언어로 서버 렌더링한다. 관련 검색·메타 화면으로 내부 링크를 연결한다. 특정 순위·검색 노출·리치 결과를 보장하지 않는다. 이후 GSC에서 같은 페이지/기간의 클릭·검색어를 비교한다.

## 4. 광고 신청 준비

현재 광고 컴포넌트는 `NEXT_PUBLIC_ADSENSE_CLIENT_ID`와 `NEXT_PUBLIC_ADSENSE_SLOT_ID`가 실제로 설정된 경우에만 사용한다. 승인이나 실제 광고 게재를 대신하는 코드가 아니다.

1. 운영자·지급 계정 결정: Google은 만 18세 이상을 요구한다. 만 18세 미만이면 부모/보호자가 자신의 Google 계정으로 신청하고 지급받는다.
2. 운영자가 AdSense에서 실제 사이트를 추가하고 요구한 확인 절차를 진행한다. 실제 publisher ID를 확보하기 전 임의 ID를 만들지 않는다.
3. 해당 계정이 제공한 `ads.txt` 항목과 광고 단위 값을 적용한다. 배치 후보는 조작 영역에서 떨어진 콘텐츠 하단 한 곳부터 검토한다.
4. 승인을 받은 뒤 제한된 배치로 광고 게재·수익·사용성·운영비를 함께 확인한다. 광고 클릭 유도 문구를 사용하지 않는다.

공개 상태 점검: `node scripts/check-monetization-readiness.mjs`. HTTP 성공만으로 광고 승인을 주장하지 않는다.
2026-10-13 공개 점검에서는 메인·개인정보·이용약관·문의·robots·sitemap이 HTTP 200이었고 `/ads.txt`는 404였다. publisher ID를 확보한 뒤 실제 제공받은 항목을 추가해야 한다.

공식 근거(2026-10-13 확인):
- https://support.google.com/adsense/answer/9724
- https://support.google.com/adsense/answer/1346295
- https://supercell.com/en/fan-content-policy/

팬 콘텐츠 유료 기능은 Supercell의 명시적 승인 없이 도입하지 않는다. 기부에는 전용 기능·혜택을 연결하지 않는다. 스폰서 콘텐츠도 팬 정책을 준수하고 비공식 서비스임을 명확히 한다. 미니게임의 게임 자산 이용 범위는 광고 신청 전에 별도로 검토해야 하며, 이 문서는 해당 권리 승인을 확정하지 않는다.

## 5. 스폰서 제안 준비

`docs/SPONSOR_PILOT_PROPOSAL.md`는 발송 가능한 제안 초안이다. 실제 광고주·수신자·가격·기간이 정해지기 전 계약/발송으로 간주하지 않는다. Google 검색 클릭을 방문자 수·광고 노출 보장으로 바꾸지 않는다.

첫 실험의 성공 기준은 운영비를 충당하는 실제 수입과 유료 재계약 가능성이다. 정책을 준수하는 단일 스폰서로 기간을 제한해 검증하고, 결과가 있기 전 광고 슬롯을 늘리지 않는다.
