# 홍보 글 초안

실제 게시 전 대상 커뮤니티의 홍보·외부 링크 규칙을 다시 확인하고 사용자 승인을 받는다.

## 국내 게임 커뮤니티용

### 제목

브롤스타즈 전적·보유 브롤러·맵 추천을 한글로 보는 개인 프로젝트를 만들었습니다

### 본문

안녕하세요. 브롤스타즈 플레이어 태그를 입력하면 프로필, 최근 25경기, 보유 브롤러의 장비와 스킨, 누적 전투 기록을 한 화면에서 볼 수 있는 개인 프로젝트를 만들었습니다.

검색된 전투 기록을 중복 없이 모아 맵별 추천, 팀 조합, 카운터도 보여주고 있습니다. 다만 이 수치는 전체 유저의 공식 통계가 아니라 사이트에서 검색된 플레이어의 전투 표본을 바탕으로 한 값입니다.

모바일에서 검색과 결과 확인이 불편한 부분, 실제 게임과 다르게 보이는 번역·승률·맵 정보가 있으면 알려주시면 감사하겠습니다.

- 서비스: https://www.brawl-o1.site/
- 코드와 데이터 산정 방식: https://github.com/psh1234567890/brawl_status_kr

Supercell과 제휴·후원·승인 관계가 없는 비공식 팬 프로젝트입니다.

## 네이버 카페·긴 글용

안녕하세요. 한국어로 브롤스타즈 전적과 보유 현황을 조금 더 편하게 확인하고 싶어서 Brawl Status KR이라는 웹 서비스를 개발하고 있습니다.

현재는 플레이어 태그 검색, 최근 25경기 분석, 보유 브롤러의 가젯·스타파워·하이퍼차지·기어·스킨 확인, 맵 추천, 팀 조합, 카운터, 스킨 카탈로그를 제공합니다. Next.js·TypeScript·PostgreSQL로 만들었고, 검색 시 받은 전투 기록은 전투 시간과 참가자 기준 지문으로 중복 저장을 막고 있습니다.

맵 추천과 카운터 수치는 전체 브롤스타즈 유저의 공식 통계가 아닙니다. 이 사이트에서 검색된 플레이어의 전투 기록이 누적된 표본이라 이용자 구성에 따라 편향될 수 있습니다. 표본 수와 계산 기준을 함께 공개하고 코드는 GitHub에서 확인할 수 있게 정리 중입니다.

직접 사용해 보시고 아래 두 가지를 알려주시면 가장 도움이 됩니다.

1. 모바일에서 태그 검색부터 결과 확인까지 막히는 부분이 있는지
2. 번역, 전투 결과, 추천 수치가 실제와 다르게 보이는 사례가 있는지

서비스: https://www.brawl-o1.site/

## 개발자·오픈소스 커뮤니티용

### 제목

검색 표본 기반 Brawl Stars 통계 서비스를 오픈소스로 정비하고 있습니다

### 본문

Brawl Status KR은 플레이어 태그 검색에서 받은 최근 전투를 PostgreSQL에 누적하고, 팀전 참가자를 펼쳐 맵·팀·카운터 통계를 계산하는 Next.js 프로젝트입니다.

이번 공개 정비에서 태그 정규화, 전투 fingerprint, UNIQUE 제약, 표본 최소치와 점수 계산, API 실패 fallback을 문서와 테스트로 맞추고 있습니다. 특히 “저장된 태그 수”와 “사용자 수”를 섞지 않고 표본 편향과 캐시 차이를 공개하는 데 초점을 두었습니다.

코드 리뷰나 큰 기능보다도 다음 기여가 필요합니다.

- 실제 구현과 문서가 다른 부분
- 익명화 fixture 기반 팀전·쇼다운 회귀 테스트
- 한국어 번역과 접근성
- DB 없이 재현 가능한 개발 환경

저장소: https://github.com/psh1234567890/brawl_status_kr
